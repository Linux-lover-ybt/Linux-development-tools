# Linux Development Tools

Linux / i.MX6ULL 开发环境与常用工具归档。

## 下载

所有安装包、开发工具和系统烧写工具均发布在
[Releases](https://github.com/Linux-lover-ybt/Linux-development-tools/releases/latest)。

文件名、原始目录、文件大小和 SHA-256 校验值见 [MANIFEST.csv](MANIFEST.csv)。
下载完成后，可在 PowerShell 中校验文件：

```powershell
Get-FileHash .\文件名 -Algorithm SHA256
```

## 内容

- i.MX6ULL 引脚复用配置工具
- 100ask i.MX6ULL Pro 系统烧写工具
- Ubuntu Qt Creator 开发工具
- Python + OpenCV 开发环境
- Windows 串口、SSH、TFTP、FTP、网络分析和远程控制工具
- Windows Git、Java、VMware Workstation、Source Insight 等开发工具
- USB 串口驱动、SD 卡格式化和镜像烧写工具

## 说明

- 压缩包如需解压密码，统一为 `100ask.org`。
- 两台 Ubuntu 虚拟机文件体积分别为 4.64 GB 和 31.35 GB，单个文件超过
  GitHub Release 的 2 GB 限制，因此暂未上传。其余工具均已发布。
